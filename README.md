## 📖 Overview

This project serves as a practical demonstration and research output from a first-year Math course, focusing on the fascinating relationship between age, pulse, and estimated blood pressure. It provides an interactive web-based tool where users can input their age and pulse rate to receive a calculated blood pressure reading. Complementing the web interface, the repository includes Python scripts that embody the mathematical model and offer further avenues for data analysis or testing the underlying logic.

The goal of this project is to visually explain and practically apply mathematical research into physiological measurements, making complex concepts accessible through an engaging user experience.

## ✨ Features

-   **Interactive Blood Pressure Estimation:** Input your age and pulse rate to get an estimated blood pressure reading directly in the browser.
-   **Visual Dial Display:** An intuitive, dynamically updating dial on the web interface to visualize the calculated blood pressure.
-   **Core Calculation Logic (Python):** Standalone Python script (`main.py`) implementing the mathematical model for blood pressure calculation.
-   **Research-Based Model:** The estimations are derived from research findings explored as part of a Math project.
-   **Simple & Accessible Interface:** Designed for ease of use, making physiological estimations straightforward.

## 🚀 Quick Start

This project consists of static HTML pages and standalone Python scripts.

### Prerequisites

-   A modern web browser (for the HTML interface).
-   Python 3.x (for running the Python scripts).

### 1. Clone the repository

```bash
git clone https://github.com/sofiaplyak/blood-pressure.git
cd blood-pressure
```

### 2. Access the Web Application

The web interface runs entirely in your browser.

-   **Introductory Page:** Open `Underpressurewebsite.html` in your web browser.
    ```bash
    # For macOS/Linux
    open Underpressurewebsite.html
    # For Windows
    start Underpressurewebsite.html
    ```
-   Alternatively, visit the [Live Demo](https://sofiaplyak.github.io/blood-pressure/Dial.html).

### 3. Run the Python Scripts (Optional)

The Python scripts are standalone and can be executed from your terminal.

-   **Run the main calculation script:**
    ```bash
    python main.py
    ```
    This script will likely prompt you for input (e.g., age, pulse) and then output the calculated blood pressure.
-   **Run the image testing script:**
    ```bash
    python testimg.py
    ```
    This script might perform tests or visual outputs related to image processing, as indicated by its name.

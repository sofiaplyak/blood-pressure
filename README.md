This repository is showing first-year project for Math subject, where we were trying to find out if is it possible to measure blood pressure using only your age and pulse.
"The UNDER Pressure website is a tool for measuring your blood pressure whenever you want and wherever, and if you do not have any required equipment for that."

Systolic pressure ≈ 100 + (age / 2) + (pulse / 10)
Diastolic pressure ≈ Systolic pressure - (pulse / 2)
P.S. the formula is not accurate because there are many others circumstances that affect on our blood pressure
